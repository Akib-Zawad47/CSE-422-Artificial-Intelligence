## ⭐ Featured Project: Customer Churn Prediction
 
A comparative study of **Logistic Regression, KNN, a Neural Network, and K-Means** on a 1,500-customer churn dataset.
 
| Model | Accuracy |
|-------|:--------:|
| Logistic Regression | 0.53 |
| KNN (k = 1) | 0.49 |
| Neural Network | 0.47 |
 
All models performed close to random guessing, suggesting the available features carry very little predictive signal for churn.
